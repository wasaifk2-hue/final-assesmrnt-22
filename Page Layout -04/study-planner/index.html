HTML Tags

Here are some of the most common HTML tags used in web pages.

<h1> to <h6>

Heading tags. h1 is the biggest, h6 is the smallest.

<h1>Main Title</h1>
<h2>Sub Title</h2>

<p>

Paragraph tag. Used for blocks of text.

<p>This is a paragraph.</p>

<a>

Anchor tag. Creates a clickable link to another page or section.

<a href="https://google.com">
    Visit Google
</a>

<img>

Image tag. Displays an image on the page. It is self-closing.

<img src="photo.jpg"
     alt="A photo">

<ul> and <li>

Unordered list and list item. Creates a bullet point list.

<ul>
    <li>Item one</li>
    <li>Item two</li>
</ul>

More HTML Tags

These tags help structure and organise the content of a page.

<div>

A generic container. Used to group elements together for styling.

<div class="box">
    <p>Content here</p>
</div>

<form> and <input>

Used to collect information from the user.

<form>
    <input type="text"
           placeholder="Name">
    <button>Submit</button>
</form>

<table>

Creates a table with rows and columns.

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>Ali</td>
        <td>20</td>
    </tr>
</table>

<header> <main> <footer>

Semantic tags. They describe the purpose of each section of the page.

<header>Top area</header>
<main>Page content</main>
<footer>Bottom area</footer>

<section> and <article>

section groups related content. article is for self-contained content.

<section>
    <article>
        <h2>Post title</h2>
        <p>Post content</p>
    </article>
</section>

CSS Properties

These are some of the most useful CSS properties for styling pages.

color

Changes the text colour.

p {
    color: blue;
}

background-color

Sets the background colour of an element.

div {
    background-color: #f5f5f5;
}

font-size

Controls the size of text.

h1 {
    font-size: 32px;
}

margin and padding

margin is space outside the element. padding is space inside it.

p {
    margin: 10px;
    padding: 5px;
}

border

Adds a border around an element.

div {
    border: 2px solid black;
}

display: flex

Makes elements sit side by side in a row.

.container {
    display: flex;
    gap: 10px;
}

width and height

Sets the size of an element.

img {
    width: 100%;
    height: 200px;
}

border-radius

Rounds the corners of an element.

button {
    border-radius: 5px;
}
